# Use ginnOS

This part is for people who use ginnOS: how to start it, and how to use
the desktop, the apps, the terminal and the settings.

- [Get started](getting-started.md): start ginnOS in QEMU or on a
  real PC, and log in.
- [The desktop](desktop.md): the panel, the launcher, windows, light and
  dark mode, log out.
- [The apps](apps.md): Mimir, Yggdrasil, Saga, Freyja, Huginn and
  Settings, with their keys.
- [The shell](shell.md): edit and run commands, pipes, jobs, and what
  the shell cannot do yet.
- [The network](networking.md): DHCP, `ping`, `host`, `fetch` and
  `curl`, names, and an address set by hand.
- [The settings files](settings-files.md): where the settings are, the
  `conf` command, and each key with its values.
