# Write programs

This part is for people who write programs for ginnOS or port programs
from other systems.

- [Set up the build tools](setup.md): the tools to build ginnOS on
  macOS, Linux, Windows and Nix.
- [Build ginnOS](building.md): the image, the build options, the tests
  and the debugger.
- [The ginnOS toolchain](toolchain.md): the compiler for ginnOS, the
  sysroot, and how to compile a program.
- [libc](libc.md): what the C library has, how it works, and what it
  does not have yet.
- [The libraries](libraries.md): gfx, heimdall, bragi, idunn and the
  others, and how to write a program for the desktop.
